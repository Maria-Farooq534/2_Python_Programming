# Student Result Management System

A menu-driven Python application built using functions, lists, dictionaries, loops, and conditionals.

## Features

- Add Student
- View All Students
- Search Student
- Update CGPA
- Delete Student
- Exit

## Concepts Practiced

- Functions
- Parameters
- Return values
- Lists
- Dictionaries
- Loops
- Searching
- Updating records
- Deleting records
- Menu-driven programs
